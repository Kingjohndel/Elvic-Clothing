# ELVIC Clothing Backend

This folder is reserved for backend source code.

The current repository contains a static storefront. It does not include a functioning authentication, database, email, payment or order-processing backend. There are no backend services to install or start yet.

When the actual backend package is added, place its server routes, service modules, database migrations, tests, dependency manifest and setup instructions here. Keep service-role keys, SMTP passwords and other credentials in private environment variables, never in source control.

The frontend's browser-local shopping bag and wishlist remain part of `../Frontend`; they are not server-side account or order services.
